Como o sistema funciona

O caminho de um cadastro, do formulário até o banco de dados.

  1. 1
    UsuárioPreenche o formulário no site (frontend em HTML, CSS e JavaScript).
  2. 2
    RequisiçãoO JavaScript envia os dados em JSON para a API.
  3. 3
    BackendNode.js + Express confere os dados e salva no banco SQLite.
  4. 4
    RespostaA API devolve o resultado e o site atualiza a lista na hora.
